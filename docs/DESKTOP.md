# 知页 Paperleaf · Windows 桌面版

桌面版将现有文献阅读器打包为独立窗口，内置运行环境，不需要打开命令行、安装 Node.js 或手工启动本地服务器。

## 安装与打开

1. 从 [GitHub Releases](https://github.com/zh-984/PaperLeaf/releases/latest) 下载 `Paperleaf-Setup-0.7.0-x64.exe`，然后双击运行。
2. 按向导安装到当前用户目录。默认不需要管理员权限。
3. 双击桌面的 **知页 Paperleaf**，或从开始菜单打开。

安装程序会创建桌面和开始菜单快捷方式。关闭最后一个窗口会同时停止后台本地服务；再次打开会恢复书架、报告、笔记和阅读位置。同一时间只运行一个实例。

Windows x64 安装包中已包含 Chromium、Node 运行时、生产服务、PDF.js 离线资源和 SQLite 引擎。正常使用不依赖源代码目录和 pnpm。`win-unpacked` 是开发验证用的免安装目录；若使用该目录，需要保留整个目录，不能只拷贝其中的 `Paperleaf.exe`。

## 数据、配置与备份

```text
%APPDATA%\Paperleaf\
  ai.env             AI 配置，仅由本地服务读取
  data\library.db    SQLite 数据库
  data\uploads\      PDF 文件
  data\tmp\          上传临时文件
  logs\desktop.log   本地启动与错误日志
```

可通过顶部 **文件 → 打开数据目录** 或左下角 **设置与隐私 → 文件与存储** 访问文献数据；通过顶部 **帮助 → 打开日志目录** 查看本机日志。关闭程序后备份整个 `%APPDATA%\Paperleaf` 目录即可。安装程序不包含开发者的 `.env`、数据库、上传文件或 API Key；更新程序时不覆盖已有资料和 AI 配置。

Web 版项目根目录的 `data/` 与桌面版数据目录相互独立，原始 Web 数据不会被删除。需要迁移旧数据时，应先关闭两个版本，并备份后将旧 `data/` 内容复制到桌面版空的数据目录；桌面版能识别已执行的 Prisma 迁移。不要覆盖已经有文献的桌面版数据库。

## AI 配置

打开左下角 **设置与隐私 → AI 配置**，在应用内填写 **API 地址、API Key、模型名称**，点保存即可生效，无需打开记事本或重启。其余参数使用文献阅读预设。Key 不回显，留空保留原值；点击“移除 Key”关闭 AI。

阅读器支持从第一页连续滚动到最后一页，记住页码和页内位置。划词点“记笔记”会保存原句及其精确位置；点页边标记打开笔记，点笔记页码回跳高亮。侧栏可切换本页/全部，保持原文与想法紧密关联。

中文文件名使用 UTF-8 接收，并从首页字体与布局推断多行标题；已有乱码记录在打开书架时自动修复。扫描件或特殊字体无法识别时可手动重命名。数据库升级前会自动备份已有文献库到 `data/library.db.backup-时间戳`，不会删除文献或笔记。

使用集成标题栏，文件、编辑、查看、帮助位于顶部，保留系统窗口按钮；Ctrl+O 导入，Ctrl+F 搜索书架，F11 全屏。左下角分栏设置集中管理导入、AI、阅读和隐私。字体整体加大，笔记按原文位置排序并与页边共用编号；默认窄栏可拖宽，正文框随内容增高。

默认导入后不自动解读，点击“开始解读”才发送全文；升级到 0.5.0 也会将自动解读设为关闭。用户仍可在常规设置中主动开启。全文文字和支持时的页面图像会分组发送给配置的 AI 服务；追问发送当前页文字、图像及有限对话历史。界面会明确显示服务地址和隐私说明。不配置 AI 也能上传、阅读和保存笔记。

在“阅读与外观”可切换浅绿、浅蓝、浅黄、纯白主题，侧栏、工具栏和标题栏同步变化，正文阅读区保持白底黑字。设置自动保存。“…”菜单可点击外部或按 Esc 收起；修复界面缩放后外层滚动在侧栏底部留下空白的问题。

## 项目书架

左侧 + 新建并命名书架；每组可独立折叠，文献菜单可移动。删除书架不会删除文献。书架、折叠状态和阅读偏好保存在本地 SQLite，更新前会自动备份已有资料库。

## 开发与重建

```powershell
pnpm install
pnpm desktop:build   # 构建独立服务、桌面壳与 NSIS 安装器
pnpm test:desktop    # 实际运行 release/win-unpacked/Paperleaf.exe
```

也可使用 `pnpm desktop:pack` 只生成免安装目录。打包脚本会在需要时下载 Electron；首轮构建需要网络获取官方打包工具。受限网络可预先将经官方校验和核验的 NSIS bundle 解压到 `.desktop-cache/nsis/nsis-bundle/`，构建器会自动复用。

桌面构建只使用生成的 `.desktop-build/`，不会将原始项目 `.env` 或 `data/` 放入包中。pnpm 链接会转换为实际依赖文件，PDF.js 的 worker、字体及原生 canvas 依赖会完整保留，避免依赖开发机上的模块路径。

窗口启用 context isolation 与 sandbox，禁用 Node integration；不向文献页面暴露文件系统接口。服务仅监听 `127.0.0.1` 的随机空闲端口。配置和数据库由后台 Node 进程读取，窗口退出时会一同关闭。

## 验证范围

自动化回归使用本机模拟服务，不调用用户付费 API。实际第三方模型的效果和可用性取决于所选服务。

安装目录为 `%LOCALAPPDATA%\Programs\Paperleaf`，桌面快捷方式仍为“知页 Paperleaf”。安装器不包含个人文献和 Key。此构建未使用代码签名证书。
